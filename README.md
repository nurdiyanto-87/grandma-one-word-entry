Entry for make.fun's ["One Word From Grandma"](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty ($5 in USDC).

The program writes exactly one word to `/output/entry.txt`: **robit** — the word a grandma would text about AI. It's her warm, slightly baffled typo for "robot": instantly readable, funny with no caption, and unmistakably about a machine.

Pure Python standard library only. Run with `python3 main.py`; it writes the word to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
